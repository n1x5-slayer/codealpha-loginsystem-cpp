# 🔐 Login & Registration System in C++

This is a simple command-line based Login and Registration System built in **C++** as part of the **CodeAlpha Internship Program**. The system allows users to register, login, and validate credentials securely using file handling.

---

## 🚀 Features

- 🔐 User Registration (Username & Password)
- 🔓 User Login with credential validation
- 🗂️ File-based user data storage (`users.txt`)
- 🔁 Retry on invalid login
- 🔒 Basic password protection logic
- 📋 Simple and clean console interface

---

## 🛠️ Technologies Used

- Language: **C++**
- File I/O: `fstream`
- IDE: Dev C++ / VS Code
- Platform: Windows
